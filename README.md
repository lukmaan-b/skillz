# skillz

A collection of Claude Code skills.

## Skills

- **react-component-creator** — guidance for writing well-structured React components, hooks, and pages.
- **diagram-guide** — draws diagrams, charts, schemas and interactive explainers as standalone offline HTML/SVG, then renders and checks them in light and dark mode. Fill in `skills/diagram-guide/assets/theme.css` before first use. The render check needs Playwright (`npm i -D playwright && npx playwright install chromium`).
